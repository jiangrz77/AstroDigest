# AstroPaperDigest v2.3.5

- Simplify the English and Chinese README; move configuration and release details into dedicated guides.
- Simplify empty Digest pages to a short message, a link to the latest nonempty digest, and an optional generation action. Remove the duplicate toolbar and date list.
- Show explicit loading, failure with Retry, and no-usable-figures states on recommended paper cards.
- Continue checking while background figure loading is active, and synchronize again when the page becomes visible. Network polling failures stop with a retryable state.
- Retry temporary figure fetch failures once, distinguish these failures from successfully checked papers with no usable figures, and allow retrying figures without regenerating the digest.
- Preserve image/caption ordering after partial downloads and recover missing or corrupt cached images. Queue background work when browsing another digest during a fetch.

- Separate the SMTP sender from the recipient list. Preserve multiple recipients across settings saves and deliver to each mailbox as a separate SMTP envelope recipient.

- Prevent hidden learned-weight inputs from blocking Settings saves: isolate their form validation and accept the precision of stored weights.
- Pin the BibTeX parser to its compatible 1.x API so clean CI and source installs keep profile extraction working.

## Validation

- Python regression suite, including source classification, bounded retries, retry routing, and empty-date navigation.
- JavaScript polling regression scenarios with virtual time beyond the previous three-minute limit.
- Local browser verification using a copy of the 2026-09-09 digest: all 39 recommended paper thumbnails load; gallery navigation and retry-to-image recovery work.
